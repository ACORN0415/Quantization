A-4: Q+FFN축소 선택 적용의 12청크 실행 판별
등록 시작2026-11-04 14:40:42 UTC, 준비·검증·검토45분 상한15:25:42 UTC.
최신 사용자는 A의 근거 있는 후속을 연속 진행하도록 승인했다. A-3의 사전 분기는
Q+FFN축소의 가정 기반 warm-forward projection>=5%일 때만 실제 적용 검사였다.
관측 A-3 FFN축소32.3903%, projection5.1624%로 해당 분기를 충족했다.
이 추정은 새로운 모델 가속 실측이나 상한이 아니다. A-2 invalid 기록을 수정하지 않는다.

목표: 기존 QVG packed·중복 decode 제거 B 기준선에서 선택적 W8A8이 실제 시간을 줄이는가.
원래 BF16 선형층 대비만 비교한다. tuned BF16 대조군은 이번 모델 실행에 적용하지 않는다.
같은 모델·프롬프트0·seed303·36 latent frames(12청크),4 denoise+1 기록, 모델60 forward/실행.
새 패키지·수동 커널·모델 다운로드0. VAE 제외, 텍스트/모델 준비·정적weight 양자화·컴파일은별도.
모든30층 self_attn.q와ffn.2만 A-2/A-3의 고정수식·설정으로 교체. K/V/O와FFN확장은그대로.
Q/FFN축소 모두3D BF16, M4680,N1536,K1536/8960에 assert. 예상외형상을조용히fallback하지않는다.
BF16 원래가중치와INT8가중치가동시에상주함을밝힌다. 배포모델압축률을주장하지않는다.

최대8실행,480 model forward. 순서 warm_B,warm_Q,pair1_B,pair1_Q,pair2_Q,pair2_B,pair3_B,pair3_Q.
각실행은동일noise/조건,empty KV와cross-attn cache. warm2개는성능비교에서제외한다.
warm_Q가finite/shape/dtype 및warm_B latent대비relativeL2<=.05를통과해야6번timed실행진행.
이는후속평가로갈공학적오차조건일뿐영상품질보존기준이아니다. 품질조건실패시범위확대없이종료한다.
모든BF16반복은warm_B와원소바이트일치, 모든Q반복은warm_Q와바이트일치해야타이밍유효.
후보전파후최종latent를직접비교하며모든중간활성값일치를뜻하지않는다.

타이밍은동기화후cache생성부터최종latent/VAE진입직전까지,텍스트/모델/정적준비/파일IO제외.
각실행60forward,current_start순서,decode1200/read3660을확인한다. GPUpeak와NVML표본을보존.
기존ReadController B와store를두팔모두사용해이미제거한중복decoder오버헤드를다시이득으로세지않는다.
CPU hook과상태검사는두팔에동일하게사용하며native.forward기록을실제수집한다.

진행기준:3대응시간감소율의중앙값>=5%,모든쌍>0,정확성조건·반복성·호출검사통과.
통과해도한프롬프트에서의latent조건과속도검사일뿐일반적영상품질·신규성주장금지.
성능미달/오차조건실패면현재선택적실행경로의추가A튜닝종료,기존기준선결과보존후B진단으로이동.
구현오류는원자료보존후상한내최소수정만허용,설정·선택층·오차기준탐색으로구제하지않는다.
