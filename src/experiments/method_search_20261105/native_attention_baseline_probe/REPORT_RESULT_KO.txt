기존 SageAttention1 구성요소의 합성 GPU 기준선 검사 — 사후 검토 전 보고

목적: 새로운 양자화 방법을 주장하기 전에, 기존 INT8 QK / FP16 PV 경로에서 K/V 변환을 반복하지 않는 단순 기준선의 비용을 확인한다.
실행: RTX 4090, Q=4680, B=1, H=12, D=128. 동일 K/V와 두 고정 Q 입력. 각 팔 2회 워밍업, 8회 측정, 실행 순서 교차. GPU 주 실행 1회, 모델·데이터셋 로드 및 설치 0회.

K 길이 | FA2 wall 중앙값(ms, 8측정) | 매번 변환 wall 중앙값(ms, 8측정) | K/V 준비값 재사용 wall 중앙값(ms, 8측정) | 대응 시간 감소 중앙값(매번 변환 대비 / FA2 대비)
4680 | 1.0657 | 1.0072 | 0.9441 | 6.22% / 11.40%
18720 | 4.0595 | 4.0687 | 3.3574 | 17.62% / 16.83%
32760 | 6.7485 | 6.8511 | 5.5630 | 18.80% / 17.55%
56160 | 11.5230 | 12.0548 | 9.8038 | 18.64% / 14.90%

정확성: 작은 2사례는 같은 양자화 표현의 독립 FP64 CPU 계산 대비 등록된 rel<=0.01 AND maxabs<=0.05 기준을 통과했다. 저장된 작은 텐서 2개로 다른 CPU 계산 경로를 사용해 재검산했으며 파일·호출수·측정행 등 총 51개 감사를 통과했다. 모든 시험 형상의 두 Q에서 전체 변환/재사용 출력의 원소 바이트 일치를 실행 코드가 확인했다. 큰 출력 원자료는 저장하지 않아 이 부분의 독립 사후 재생산은 하지 않았다.
FA2와의 상대 Frobenius 차이는 약 1.34~1.37%였다. 같은 표현의 수치 검사 통과와 BF16 FA2 동등성·영상 품질 보존은 다른 주장이다. 출력 dtype은 BF16, PV 연산 입력 V는 FP16이다.

자원: 전체 5.010490초/900초, exit 0. 관측 과정 트리 peak RSS 1038802944B. 주 GPU 실행 1개 외에 Triton CPU 컴파일 자식이 있어 관측 프로세스 ID는 총 11개였다. 종료 시 소유 프로세스 그룹과 GPU compute app이 없었다.
제약: 기존 두 Triton 수학 모듈에 패딩/유효 키 마스크와 K 평균 처리 어댑터를 적용한 경로다. 원 high-level API 그대로의 재현이나 Sage2/2++ SOTA 비교가 아니다. 마스크·평균·Q 양자화와 관측 래퍼 비용을 포함한다. K/V 최초 준비 및 JIT/정확성 확인 비용은 별도 setup에 포함되어 순수 준비비용이나 생산 환경 손익분기점을 분리 측정하지 못했다. 정적 합성 K/V의 반복 호출 결과로 실제 생성 전체 가속·퇴거/추가 처리·저비트 PRQ 저장 압축 이득을 입증하지 않는다.

현재 판단: 기존 구성요소를 이용한 실행 가능한 단순 기준선을 확보했고, 이 합성 반복 조건에서는 K/V 준비값 재사용의 측정 이득이 있다. 이것은 새 방법론 효과가 아니다. 실제 Claude Opus 5.5 사후 검토가 완료됐으며, 결과를 무효로 만드는 결함은 발견되지 않았다. R1 시간 표기와 R2 FA2 비교 범위를 수정했고 R3 단일 실행 한계를 반영했다. 추가 GPU 실행은 이 보고서로 승인되지 않는다.

직접 확인: 단일 GPU 실행, 작은 텐서 독립 CPU 재계산, 저장 타이밍 대응 재집계, 소스/결합 파일 SHA 확인. 미확인: 큰 텐서 독립 재계산, 영상 품질, 실제 모델 속도, Sage2++ 대비 성능, 장시간 실행 잡음/다중 GPU 일반화.

사후 검토 반영: FA2 대비 약 11~18%의 호출 시간 감소는 K/V 준비값 재사용 팔에 한정되며 최초 준비 비용 상각을 가정한다. 매번 변환 팔은 K=4680에서 FA2보다 약 5.5% 빠르지만 K=18720에서는 거의 같고, K=32760/56160에서는 약 1.5%/4.6% 느리다. INT8 커널 자체의 일반적 우위로 해석하지 않는다. 단일 실행의 형상당 대응 8개 측정이므로 실행 간 재현성·클럭·온도 변화는 측정하지 않았다. 이 한계를 해결하기 위한 추가 실행을 자동으로 시작하지 않는다.
