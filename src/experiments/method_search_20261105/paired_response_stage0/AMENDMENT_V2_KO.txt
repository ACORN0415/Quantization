dense 상한을 넘으면 구현무효다. cap 내로 등록한 팔이 cap을 넘어서도 무효다.
주 기준선 하나라도 invalid/누락이면 남은 팔의 최소값으로 통과시킬 수 없다. 현재 감독기는
어떤 팔의 실행 실패에서도 정지하므로 더 보수적으로 전체 판단불가를 남긴다.

=4,967,208B. FM3/FM8은 R_fp32 기반 raw-M 상주 변형에 대한 비용점이며 모든 가능한
FULL 기반 유도-M 또는 다른 dtype 변형에 대한 불가능성 주장은 아니다.
byte 범위: 실제 tensor/packet 코드·scale·stored header·인덱스·label·공유행렬/λ를 센다.
모든 팔의 공통 외부 manifest JSON, 파일 컨테이너, Python 객체·shape/실행 코드·seed 등

[fallback·분모 기록]

분모1536으로 나눠 ≤0.001, 즉 0개 또는1개일 때만 기존 fallback 조건을 통과한다.
all_fallback, cast 실패 등 원인별 진단이 겹쳐도 같은 pair를 여러 번 세지 않는다.

0상태 우회 통과는 nonzero reader 산술 검증이 아니다. 기존 비제로 합성/core 회귀는

finite 값이 없으면 분위수는 null이다. 이는 상쇄/폭주 위험 설명용으로 추가 gate가 아니다.

[상태 provenance와 QKSA]
OMEGA_BINDINGS_V2.json은 실제 자료 없이 생성한 seed17/29/43의 planned Omega hash를
고정한다. 같은 seed는 두 층에서 같은 값이지만 별도로 소유하고 각층196,608B를 센다.
생성 dtype FP32/device CPU/torch version/shape/seed/layer/hash를 기록하고 각 ChunkState

검사한 상태로 읽는다. core는 변경하지 않는다.
BIT8도 layer/chunk/head/state bytes hash/packet hash를 묶어 restore 전에 확인한다.
p0 raw C hash와 K[0:28080] 범위, R_fp32 복원, 선택 점수12개를 PREPARE 결과에 기록한다.
BIT8 scale 실패는 clamp나 다른 head로 구제하지 않고 invalid, 전체판단불가다.
QKSA는 sqrt128로 나눈 logits에서 softmax 전에, 과거28080토큰에만 bias를 뺀다.
rotation은 H128이며 FULL U를 넘기지 않는다. [3,98,1,12,128] scale에서 frame별

mask는 원 dense visible-window와 같이 없다. FULLP1Q/RP3Q의 원래 scale 사용은 단순
조합이며 PSAC 이후 잔차가 독립 균등이라는 보장을 하지 않는다.
