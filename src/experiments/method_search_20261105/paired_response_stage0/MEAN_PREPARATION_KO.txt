고정 p0 K평균 제거 기준선 — 합성 준비 완료
실제 Opus 제안으로 추가하는 단순 대조이며 새 방법이 아니다. 본 구현의 실제 Opus 코드 검토는 미완료다. root가 후속 검토를 연결한다.

수치·정보 계약
원좌표 post-RoPE p0 과거6청크 K의 token 평균 mu를 고정 FP32[12,128]로 저장한다. 평가 입력의 통계로 갱신하지 않는다. make_mean은 외부 BF16 K 텐서 또는 iterable만 받아 token 수로 가중한 FP64 합산/나눗셈을 수행한 후 FP32 저장값으로 변환한다. raw 자료 접근이나 파일 로드, p0/평가 식별을 함수가 수행하지 않는다. driver가 p0 과거만 전달하고 provenance를 고정해야 한다.
실제 청크의 K는 (K.float()-mu).BF16로 중심화한 뒤 동결 common.encode_k(...,'R_fp32')를 그대로 사용한다. 복원은 common.restore 뒤 (restored.float()+mu).BF16다. 현재 청크 K에는 개입하지 않으며 이 함수는 완료된 과거 청크만 입력받는다. H128/frame1560+padding8/group16/FP16 scale/FP32 RTN/BF16 dequant 및 역회전 시점은 원래 common 함수를 그대로 따른다.
mu의 모든 값이 0이면 subtract/add를 건너뛰고 원래 경로를 호출한다. 이는 signed zero까지 원래 packet/restore byte를 보존하기 위한 무개입 대조다. mu가 0이 아니면 subtract/add의 BF16 반올림 자체가 원본을 변경할 수 있다. 양자화를 끈 일반 평균 제거 왕복이 bit identity라고 주장하지 않는다. 합성 예 0.001953125에서 mu=1을 빼고 BF16, 다시 더하고 BF16이면 0이 된다.

scale 및 오류 계약
기존 common의 FP16 scale 왕복 assert는 ValueError로 전달한다. packet 복원 전 FP16 scale의 유한·양수 및 원래 BF16 scale 표현가능성을 검사한다. zero/tiny/negative/overflow/nonfinite 상태를 새 clamp나 fallback으로 구제하지 않는다. 중심화·복원 결과의 비유한도 거부한다. 이 오류 검사는 새로운 품질 허용오차가 아니다.

API
prepare_mean(mu_FP32[12,128]) -> MeanState(mean)
make_mean(keysBF16) -> MeanState(mean)
encode(K_BF16[1,4680,12,128],state) -> 기존 common K packet dict
restore(packet,state) -> 원좌표 BF16 동일 shape
state.to_bytes()/MeanState.from_bytes(data), state.nbytes()/storage_bytes()
make_mean의 입력은 BF16[N,12,128] 또는 BF16[1,N,12,128], 또는 이 tensor들의 iterable이다. prepare_mean은 입력의 owned contiguous/no_grad 사본을 만든다. 모든 실행 entry는 no_grad이며 입력을 수정하지 않는다.
mean_baseline.py는 import 시 common.py SHA436f7b2762397ecce840b91feb535094a9008c54066e4e796c3df248f9071c35를 검증한다. 과거 실행의 guard/LOCK/capture/replay는 호출하지 않는다. 외부 프로그램의 CUDA 환경이나 grad mode를 module import에서 바꾸지 않는다. selftest만 CPU4 및 CUDA_VISIBLE_DEVICES 빈 값으로 실행한다.

상태·비용
공유 mu는 FP32 12*128*4=6,144B다. 고정 형상과 dtype는 코드/driver manifest에 묶으며 raw state 직렬화도 정확히6,144B다. 각 청크의 기존 R_fp32 packet은4,515,841B로 그대로다. 여섯 청크에 mu를 한 번만 공유하므로 추가 operational tensor/packet bytes는6,144B다. 기존 공통 H12865,536B, Python/allocator/파일 포맷·host/device 복사와 FP64 평균 fit workspace는 별도다. 실제 peak 및 GPU 비용은 확인하지 않았다. caller가 원래 mu 사본을 계속 보유하면 그 복제본도 별도 계측해야 한다.
