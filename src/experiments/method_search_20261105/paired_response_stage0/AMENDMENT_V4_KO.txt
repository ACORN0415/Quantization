Stage0 V4 — tensor byte hash의 singleton stride 방어
2026-11-05. 실제 자료/효과/GPU는0이며, root가 승인한 격리 생산형상 합성검사의 결함 수정이다.

발견
복사된 V3의 전체 합성 pipeline은 prepare_layer의 rank1 BF16 basis 저장/재로드 해시에서
RuntimeError: self.stride(-1) must be 1 to view BFloat16 as Byte, but got 128을 냈다.
[12,128,1], stride(128,1,128)는 contiguous=True여도 마지막 singleton stride가128이다.
따라서 contiguous()가 복사하지 않고, element size가 다른 view(uint8)가 실패했다.
이 오류는 초기 Omega 제어경로 6사례와 helper 51건 검사에서 실행되지 않은 경로다.
전체 runtime 검사 필요성을 확인했으며 이를 방법의 음성 결과로 처리하지 않는다.

최소 수정
flat=x.detach().contiguous().reshape(-1)
if flat.stride(0)!=1:
    flat=torch.empty(flat.numel(), dtype=flat.dtype, device=flat.device).copy_(flat)
return sha256(flat.view(uint8).numpy().tobytes())
shape/dtype는 tensor_digest의 기존 별도 필드에 남는다. 원본 tensor는 변경하지 않는다.
root/독립 Codex는 all-singleton[1,1],stride(128,128)에서 flatten만으로도 실패함을 확인했다.
따라서 stride1이 아닌 경우 소유한 1차원 저장소로 복사하는 방어까지 반영했다.
기존 해시를 계산할 수 있던 입력은 동일한 byte digest를 유지한다. 수식/scale/팔/선택/
cap/과학적 gate/입력은 변경하지 않았다. 행정 source manifest는 SOURCES_V4.json이다.
