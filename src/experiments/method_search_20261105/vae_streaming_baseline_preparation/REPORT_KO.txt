목적과 판정
원 BF16 VAE의 full latent denormalization·conv2·126회 decoder와 feature cache 계약을 유지하고 출력 누적만 CPU 순차 전달로 교체했다. 동일 latent·가중치를 새로 적재한 두 경로에서 501 RGB 프레임의 shape/dtype/논리 원소 바이트가 worker의 직접 비교에서 모두 일치했다. 등록된 trace 계약도 통과했다. 이는 강한 기존 실행 기준선의 확보이며 새로운 양자화 방법의 효과가 아니다.

근거의 범위
실제 출력 바이트 비교는 worker가 수행했다. 원 RGB를 디스크에 보존하지 않았으므로 이후 저장 JSON/501 hash/trace 감사는 독립 501 원소 재생산이 아니다. 이 한 latent·501프레임·RTX4090·BF16·고정 flags의 비교이며 다른 길이·batch·VAE·원래 생성 harness 전체를 검증하지 않았다. 이전 precision probe와는 affine 위치가 다르고 이번 두 팔에 공통으로 GPU float/clamp/affine을 적용했다.

연구 판단
BF16 기준선을 더 강하게 만든 뒤에도 남은 state 압축 후보는 가까운 선행과 단순 RTN/scale 선택 대비 독립 이득이 필요하다. 일반적인 tap 분해/group scale 초안은 기존 계산과 겹쳐 별도 종료했다. future-state rounding은 아직 수학·선행 독립 비판 중인 미채택 가설이며 효과 실험을 시작하지 않았다.
