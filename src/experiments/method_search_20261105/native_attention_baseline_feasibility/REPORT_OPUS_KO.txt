선정안 1개: SageAttention 공식 repo의 순수 Triton 경로 sageattn_qk_int8_pv_fp16_triton (CUDA 재빌드 없음)
- 성격과 한계
  - INT8 QK(Q 128행, K 64토큰 블록별 scale) + FP16 PV로 구성된 SageAttention1 계열 Triton kernel이다.
  - 같은 repo의 Sage2 CUDA 경로(INT8 QK per-warp/thread + FP8 PV)나 Sage2++보다 약하거나 오래된 기준선이다. SOTA 기준선이나 Sage2·Sage2++ 대체로 쓰지 않는다.
- 소스 사실 (요약 인용)
  - core.py의 sageattn_qk_int8_pv_fp16_triton: quantization_backend 기본값 "triton", tensor_layout "HND"/"NHD", is_causal False, sm_scale 기본 1/sqrt(head_dim 원래 값), smooth_k True(km = k의 seq 평균을 빼는 것), return_lse 옵션.
    - assert: CUDA, fp16 또는 bf16, 같은 device와 dtype, 마지막 dim contiguous.
    - head_dim은 128 이하이면 padding하고 128을 넘으면 ValueError다. D128은 그대로 쓴다. 출력을 원래 head_dim으로 자른다.
  - triton/quant_per_block.per_block_int8(q,k,km,BLKQ=128,BLKK=64,sm_scale,tensor_layout): Q에 sm_scale×1.44269504(log2 e)를 접어 넣고, int8 값과 FP32 scale을 낸다. km이 있으면 k에서 뺀다. import는 torch와 triton뿐이다.
  - triton/attn_qk_int8_per_block.forward(q,k,v,q_scale,k_scale,tensor_layout,attn_mask,output_dtype=fp16,return_lse)
    - qo_len과 kv_len을 각 tensor에서 따로 얻고 경계를 mask한다. 따라서 rectangular를 지원한다.
    - BLOCK_M 128, BLOCK_N 64, GQA 지원. assert는 없다. import는 torch, math, triton뿐이다.
- 미래 형상(B1/H12/D128, Q 4680, K 4680/18720/32760/56160, noncausal): source 계약상 지원된다(qo와 kv 길이 분리, 비배수 길이 masking, D128 무padding, HND/NHD).
  - Triton 3.2에서 실제 컴파일되는지, 수치, 성능은 미검증이다. setup.py에는 Triton 요구 버전이 없다.
- 차단 사실과 최소 우회
  - 공식 package를 import하면 __init__ → core가 `from .quant import ...`를 하고, quant.py는 `from . import _fused`(컴파일 extension)를 try/except 없이 import한다.
  - 따라서 CUDA 빌드 없이는 `import sageattention`이 실패한다(소스 판독).
  - core의 sm80/89/90_compile import는 try/except로 보호돼 있으므로 문제없다.
  - 최소 adaptation(새 방법 아님, 명시적 import adapter, 구현·실행은 하지 않음)
    1) 고정 commit의 sageattention/ source를 읽기 전용 디렉터리에 둔다. 합성 package 'sageattention'의 __path__를 그 디렉터리로 지정한다(원 __init__는 실행하지 않음).

  - 이때 core가 top-level에서 import하는 Triton 파일 다섯 개(quant_per_block_varlen, attn_qk_int8_per_block_causal, attn_qk_int8_block_varlen, attn_qk_int8_per_block_causal_varlen, quant_per_thread)도 같은 commit 원문으로 있어야 한다.
