원 실행은 CPU에서 전체 checkpoint를 복원한 뒤 predictor의 named_buffers 집합 비교에서 중단됐다. CPU 출력 비교·DINO state_dict 복원·GPU 실행은 하지 않았다. 원 RESULT와 실패 상태는 그대로 둔다.

기존 inert pickle opcode parser로 data.pkl의 객체 상태를 다시 읽었다. 원 predictor의 여섯 Attention 객체는 _buffers가 비어 있고 bias를 일반 Tensor 속성으로 저장했다. 각 bias는 FP32 [1,1,588,588], offset0, stride가연속이며 여섯 storage를 참조한다. 저장방식 차이를 값 차이로 취급한 원 named_buffers 집합 조건은 이 checkpoint의 forward 동등성 검사로 적절하지 않았다.

별도 raw-storage 읽기 명세로 여섯 mask storage8,297,856B를 읽었다. 파일 byteorder는 little이며, 3프레임×196patch의 block-causal FP32 0/1 마스크와 전부 원소 바이트가 같았다. Torch·pickle 역직렬화/모델생성/GPU/네트워크0이다. 이는 mask 값에 대한 근거이며 모델 출력 동등성은 아직 모른다.
