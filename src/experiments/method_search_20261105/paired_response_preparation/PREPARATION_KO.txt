1. 구현한 수학과 API
core.PairedResponse.gaussian(heads, dim, rank, seed)는 FP32 IID 표준정규 Omega[H,D,R] 하나를 만든다. 단위길이 정규화나 QR을 적용하지 않는다. 실제로 소유한 map은 self.omega 하나이며 phi/psi에 같은 map을 쓴다. rank/seed는 호출 인수이고 실자료 설정을 확정한 것이 아니다.
phi(x)=psi(x)=exp(Omega^T x/D^(1/4) - ||x/D^(1/4)||^2/2)/sqrt(R).
이 feature의 목표 kernel은 exp(q·k/sqrt(D))다. 입력 Q와 K는 같은 좌표계여야 하며 회전/RoPE/원래 attention 경로는 이 core에 포함하지 않는다.
summarize(id,K,Khat,Vhat)는 K-only Dz=sum[psi(K)-psi(Khat)], DN=sum차분*Vhat를 만든다. feature마다 원본과 복원 전체 토큰의 최대 log-feature를 공통 offset으로 택한다. 저장은 exp(-offset)으로 스케일된 Dz FP32[H,R], DN FP32[H,R,Dv], offset FP64[H,R]다. 가까운 지수값의 차는 expm1으로 계산한다. 모든 준비 contraction·누산은 FP64이며 입력 또는 통계의 비유한/FP32 저장 overflow는 PreparationError로 거부한다. 무효 상태를 조용히 양자화 복구하지 않는다.
append는 청크 id별 상태를 보유하고 중복 id를 거부한다. evict는 해당 상태만 제거한다. 모든 상태에 같은 map이 유지되어야 한다. 상태에 autograd graph가 남지 않도록 no_grad를 적용했다. 원본 K/Khat/Vhat나 feature 행렬은 상태에 저장하지 않는다.
read(Q,Ohat,logZhat,min_denominator_ratio=외부인수)는 각 청크 offset과 query feature, native logZ를 결합한다. 전체 청크·feature에서 공통 query별 exponent를 빼고 분자·분모를 함께 계산한다. 서로 다른 청크 offset을 같은 값인 것처럼 더하지 않는다. 호출자는 현재 retained KV와 같은 native Ohat/logZ를 제공해야 한다. Q/현재 BF16 attention/마스크/logZ 추출 경로 자체는 아직 구현하지 않았다.

2. 수치 실패 처리와 기록
- 모든 상태가 정확히 0이거나 비어 있으면 native Ohat를 그대로 복사해 반환한다. 이는 무개입 비트 일치를 보존한다. FP32 underflow로 상태가 0이 된 경우도 이 경로에 들어갈 수 있으므로 summarize 진단을 함께 보존해야 한다. zero bypass가 원본=복원이었다는 증명은 아니다.
- min_denominator_ratio는 필수 외부 인수다. 이번 합성 검사에서 .1을 사용했을 뿐 실제 캡처 gate/fallback 기준을 등록하지 않았다.
- 비유한 상태·query/logZ·중간 log, 양수가 아니거나 외부 문턱보다 작은 분모, 스케일된 native base의 underflow, 출력/출력 dtype 변환의 비유한 값은 해당 query 또는 확인 불가능한 전체 batch에서 원래 Ohat로 fallback한다. 반환 fallback mask와 원인별 count를 제공한다. native Ohat 자체가 비유한이면 유효 fallback이 없으므로 예외다.
- feature exp underflow, 순진한 exp 차감의 충돌, nonzero log 차의 소실, FP32 상태 변환 underflow, 읽기 coefficient underflow, 직접 exp라면 overflow할 항 수, native base underflow를 별도 기록한다. 일부 항의 underflow는 기록 후 계산을 계속하며 이를 정확한 값 보존으로 주장하지 않는다.
- 안정화는 원래 큰 exp를 직접 만들지 않지만 높은 노름에서의 Gaussian feature 분산이나 FP32 요약 오차를 해결한 것은 아니다. 일부 fallback 또는 zero state가 생겨 원래 출력이 유지된 것을 개선으로 세면 안 된다.
