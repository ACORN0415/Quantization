# 방법 1 후속 개발 검사: 평균 보존

2026-10-30. 첫 54행 확인 후 설계한 사후 개발 탐색. 확증 검정 아님.
동일 rank의 SVD 최적 tensor 잔차도 RTN3/4보다 크므로 열 선택 개선만으로
전체 tensor 왜곡을 줄이기는 어렵다. 그러나 tensor MSE는 attention 출력
오차가 아니므로, 출력에 중요한 편향을 작은 메타데이터로 보완한다.

기존 common_fourier 상태를 그대로 두고, 실제 decode와 원래 V의 차이를
각 프레임/head/channel의 공간축으로 평균하여 FP16 보정값을 저장한다.
추가 payload는 3*12*128*2=9216 bytes. 각 상태의 원래 rank를 유지하고
총 바이트가 RTN 예산 이하인지 확인한다. 미래 query는 보정 fitting에 사용하지 않는다.
평균 보존은 기존 압축 원리이며 새 알고리즘 신규성을 주장하지 않는다.
대조: 원래 common, RTN, 동일 rank의 FP16 SVD factor 표현(평균 보존 아님).
SVD는 선택 열의 한계를 진단하는 참고이며 실제 FP16 factor 바이트를 기록한다.
두 프롬프트 모두 RTN D 대비 10% 개선이라는 기존 진행 조건을 유지한다.
개발 데이터 재사용, V-only 및 새 청크 기여만 측정한다는 한계를 유지한다.
