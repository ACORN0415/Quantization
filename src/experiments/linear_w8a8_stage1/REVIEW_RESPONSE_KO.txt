Claude Fable 독립 검토에 대한 조정자 판단, 2026-11-04

실제 Claude Fable 5.1 채팅의 검토를 수신했다. 코드·결과·CPU 감사 검토이며 최종 보고서 전문 검토는 아니다.
다음 지적은 수용했고 REPORT_KO.txt에 명시했다.
1. unfused torch._int_mm 구현의 종료와 전체 W8A8/linear 양자화 방향의 종료를 구분한다.
2. 정확성 캡처는 block0·timestep937.5·한 프롬프트다. 30층·다른 시간·영상 품질로 확대하지 않는다.
3. FP32 참조→BF16 비교는 마지막 반올림을 포함한 구현 검사이며 모델 품질 근거가 아니다.
4. operators.json의 부모 annotation inclusive 시간과 자식 시간을 더하지 않는다.
   보고서는 CUDA hook 사건과 trace cat=kernel의 GEMM 집계만 별도 표시한다.
5. 첫 청크 profiler wall time·초기화 비용·공통 상주 메모리와 경로별 allocator 증가량을 구분한다.
6. assert 실패 시 해당 형상의 부분 기록이 남지 않는 실행기 한계를 기록한다. 세 형상 모두 통과한
   현재 결과에는 영향이 없고, frozen 코드를 수정하거나 새 GPU 실행을 하지 않는다.

검토자의 아래 설명은 그대로 결론으로 채택하지 않았다.
- FP32 elementwise pass가 초과 지연을 설명한다는 트래픽 계산: 그럴듯한 설명이지만 단계별 시간이 없으므로
  병목의 직접 측정으로 쓰지 않는다. 보고서는 중간 배열과 peak 증가라는 관측만 확정한다.
- 형상이 같으면 타이밍이 다른 모듈에도 일반화된다는 설명: layout·stride·dispatch·상주 상태도 영향을 줄 수 있어
  동일 조건의 형상 진단으로 범위를 제한한다.
- 첫 청크의 linear 비중이 항상 최대라는 설명: 긴 문맥에서 attention이 늘어날 구조적 근거는 있으나
  모든 청크를 측정하지 않았으므로 보편적인 최대값 또는 전체 평균의 엄밀한 상한이라고 부르지 않는다.
- 후보 한 번을 프로파일하면 fused 경로 상한을 알 수 있다는 선택 제안: 단계별 프로파일은 진단에 도움이 되지만
  커널 융합 후 메모리 이동·스케줄링·오버랩도 달라져 엄밀한 상한이 되지는 않는다. 추가 GPU 실행은 하지 않았다.
- 기억 기반 RTX4090 피크 사양과 이론 처리량 수치는 출처를 새로 검증하지 않았으므로 보고서 근거에서 제외했다.

결정: 현재 단순 W8A8 경로의 전체 모델 적용은 진행하지 않는다. 실제 linear 비용과 세 형상 자료를 보존한다.
복잡한 커널 개발·이식이나 B/C안 자동 실행은 시작하지 않는다. 이번 A안의 제한된 진단을 완료한다.
