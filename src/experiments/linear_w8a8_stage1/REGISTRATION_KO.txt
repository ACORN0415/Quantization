W8A8: 대칭 [-127,127], nearest-even RTN, W는 출력채널별 FP32 scale, X는 행별 FP32 scale.
W의 양자화와 INT8 전치/연속화는 정적 준비 비용으로 별도 측정한다. 실행 시간에는 X 양자화,
torch._int_mm의 INT32 누산, FP32 scale 적용과 bias, BF16 출력 변환·reshape를 전부 포함한다.
BF16 대조는 동일 X/W/bias의 torch.nn.functional.linear. 별도 fused 커널을 만들지 않는다.
torchao/vllm은 현재 설치되지 않았으므로 비교 범위는 이 단순 PyTorch 경로다.

정확성은 속도 결과 전에 판정한다.
1. 작은 정수 행렬 3사례(무작위·0·극값)에서 torch._int_mm과 CPU INT64 직접 합산의 모든 원소 정확 일치.
2. 실제 입력에서는 등록한 INT8 범위와 K*127^2<2^31을 확인한다. 첫/마지막 최대4행·첫16출력의
   INT32 결과를 CPU INT64와 비교한다. 이 부분 검사를 전체 정수 출력 검사라고 표현하지 않는다.
3. 같은 양자화 정수와 scale의 FP32 참조와 비교해 최종 BF16 출력의 relative-L2<=0.002,
   모든 원소 abs오차<=0.02+0.02*abs(참조), finite/shape/dtype 일치.
4. 모델에서 캡처한 BF16 출력과 native BF16 replay는 모든 원소 바이트 일치를 우선 검사한다.
   일치하지 않으면 성능 판정에 쓰지 않고 구현 유효성 문제로 보고한다.
5. BF16 원래 출력 대비 W8A8 relative-L2<=0.05는 다음 검토로 넘길 공학적 선별 기준이다.
   영상 품질 동등성 기준이 아니며 통과해도 모델 품질 성공을 뜻하지 않는다. 실패도 결과로 보존한다.
