## 고정 조건

RTX4090, Self-Forcing1.3B, 기존 개발 p00/seed303,36잠재프레임. QVG 공식 revision `0601468f2dbba6a17ac7086faec6d41527cad188`, INT2/group64/centroids256/1-stage/k-means2회, 8생성청크 단위 압축이다. 모델·코덱·문맥·RoPE·attention·원본 난수 일정을 고정했다.

U는 공식 read, B는 중복 decoder 호출만 제거, R은 B에서1GiB pool에 완전한 K/V span을 처음4층까지 유지한다. 주 비교는B/R이다. 모든 팔에서 진단용 CPU offload/reload를 끄고 text를 선계산했다. VAE는 실행하지 않았다. 타이밍은 pool/cache 초기화부터 최종 latent까지이며 최초 복원·압축·연결·관리 비용을 포함한다.

질문은 **복원한 값을 추가 메모리에 보관하면, 다음 읽기에서 복원을 생략하는 이득이 전체 생성 시간에서도 남는가**이다. U→B는 중복 계산 제거이고, B→R이 재사용의 추가 효과다. U의 호출 수 감소를 R의 성능 개선으로 계산하지 않는다.

```text
U: packed span → decoder 두 번 → 복원값 연결 → RoPE/attention
B: packed span → decoder 한 번 → 복원값 연결 → RoPE/attention
R: 보관값이 있으면 사용 / 없으면 B처럼 복원 후 보관 → 연결 → RoPE/attention
```

## 정확성과 실제 호출

| 실행 | decoder 호출 | attention 입력 검사 | 최종 latent |
|---|---:|---|---|
| gate_U | 2400 | 5400 tensors 원소 바이트 기록 | 기준 |
| gate_B | 1200 | 5400 tensors 원소 바이트 직접 일치 | True |
| gate_R | 1048 | 5400 tensors 원소 바이트 직접 일치 | True |

입력 검사는 실제 native self-attention의 Q/K/V 전체를 대상으로 한다. 무손실 prefix-delta/zstd 테이프를 복원해 전체 원소 바이트를 비교하며 해시만 비교하지 않는다. 타이밍에서는 이 검사를 끈다. 생성60forward×30층이며 decoder 호출은 실제 entry에서 계수한다.

**검증 실행의 시간은 성능 비교에 쓰지 않는다.** gate_U/B/R의 `generation_s`에는 입력 테이프의 저장·복원·CPU 전송·전 원소 비교가 포함된다. 결과 JSON의 `time_scope`에 있는 파일 I/O 제외 문구는 latent 저장과 일반 timed 경계에 대한 설명이며, 검증 테이프 I/O까지 제외했다는 뜻으로 읽으면 안 된다. U는 별도 timed 표본이 없으므로 U→B의 전체 생성 가속률도 이번 자료로 추정하지 않는다. 모든 timed 실행에도 공통 청크 진행 로그를 기록하는 비용은 포함된다.

NVML은0.5초 표본이므로 연속적인 실제 peak의 정확한 관측이라고 주장하지 않는다. 실행 순서는BR/RB/BR이며 표의 시간은 계측을 켠 profile 실행 시간이 아니다.

| 대응 쌍 | B 초 | R 초 | R의 시간 감소율 |
|---|---:|---:|---:|

대응 감소율 중앙값 0.113%, 범위 [0.099%, 0.312%]. 3쌍은 제한된 진단이며 모집단의 유의한 속도 향상을 입증하는 표본으로 취급하지 않는다.

감소율은 `100 × (B 시간 − R 시간) / B 시간`이다. 양수는 R이 빠르고 음수는 R이 느리다는 뜻이다. 5%는 사전 등록한 연구 진행 기준이며, 통계적 유의성의 경계가 아니다.

별도 profile_B 전체 생성 시간은 24.6260초다. 그 안에서 decoder event 구간 합은 0.2602초, decode+layout 구간 합은 0.5777초였다. 두 구간은 포함 관계이므로 더하지 않는다.

별도 B 프로파일에서 decoder 구간은 전체의 1.057%, decode+layout 구간은 2.346%였다. 현재 pool이 제거하는 호출 비율152/1200을 곱한 추정은 0.297%다.

이는 층별 비용이 균일하다는 가정의 낙관적 비용 추정이며 엄밀한 절약 상한이 아니다. 중첩된 event 구간을 합산하지 않았다. 이 추정과 실제 전체 시간 차이를 함께 보고 판단한다.

## 연구 판단

등록한 세 대응 쌍의 시간 감소율과 프로파일 추정이 모두 5% 진행 기준 미만이다. 따라서 **이 입력·길이·1 GiB 예산에서 복잡한 선택기를 개발하는 단계로 진행하지 않는다.** 작은 실제 구현으로 확인한 이득과 제거 가능한 비용의 추정이 모두 연구 확장을 뒷받침하지 못했다. 다른 문맥 길이나 더 큰 유지 예산의 불가능성을 증명한 것은 아니다.

남는 결과는 동일 출력을 유지하는 단순 구현과 그 비용의 측정이다. 공식 read의 중복 복원을 제거할 수 있다는 관측은 구현 정리의 근거이지만, U의 별도 timed 측정이 없으므로 그 자체의 가속률은 보고하지 않는다. 이 진단만으로 새 양자화 방법이나 논문 신규성을 확보했다고 판단하지 않는다.

## 해석 범위

- 한 입력·한 생성 길이·한 유지 예산·한 GPU의 진단이다. 다른 조건의 가능성을 부정하지 않는다.
- QVG 복원 후 attention 경로의 결과이며 동일 코덱 fused attention과 비교하지 않았다.
- 유지 공간은 추가 메모리 사용이다. 같은 실측 사용량에서의 우위나 Pareto 개선으로 바꾸지 않는다.
- H2의 구성용/미사용 조건 예측이나 regret은 이번 단계에서 수행하지 않았다.
- 코드·입력·예산·무효/미완료 기록은 아래 자료에 남기며 완료한 증거만 주장한다.
