# 국소 KV 대응 + 학습 예측 개발 진단 — NO-GO

2026-10-29. [계획](../DENSE_MOTION_DEVELOPMENT.md)을 `aa7ccfe`로 커밋한 뒤 실행했다. 이전 전역 이동 NO-GO는 유지하고, 사용자의 다음 실험 요청으로 연 **별도 개발 가설**이다. 이미 본 캡처를 사용한 탐색 진단이며, 새 보류 연구가 아니다.

**국소 대응은 오차를 줄였지만, 학습된 동일 위치 기준선 대비 추가 개선이 2.27%/3.12%로 사전에 고정한 5%에 못 미쳤다.** 지도 저장량 조건은 통과했다. 두 입력 모두의 5% 개선을 요구했으므로 이번 변형은 NO-GO로 종료한다. 영상 생성으로 확대하거나 반경·입력을 바꿔 기준을 구제하지 않는다.

## 비교와 결과

개발 p0/p4, seed101에서 청크 0/1로 feature별 affine `a*reference+b`를 각각 적합하고, **청크 6/7에서만** 평가했다. 층 0/14/29, 독립 프레임 쌍 0→1/1→2를 사용했다. 참조는 직접 INT4 양자화 후 복원한 프레임이며, 이전 잔차 복원을 참조로 잇지 않는다. 계수는 평가 구간에서 적합하지 않았다. 두 프롬프트도 평가 구간도 앞선 연구에서 이미 사용한 개발 자료이므로 보류 일반화로 해석하지 않는다.

지도는 층0의 현재 pre-RoPE K와 복원 참조 K 사이 예측 MSE를 목적 토큰마다 최소화한다. 반경 2의 유효 source만 허용하고 zero predictor·경계 제외·wrap을 쓰지 않았다. 모든 층·K/V가 같은 지도를 공유한다. 실제 물체 움직임이나 optical flow를 알아냈다는 뜻은 아니다. 현재 K는 encode 시점에 존재하며 미래 query/프레임은 쓰지 않는다.

다음은 K/V 상대 L2를 평균한 뒤 층·프레임 쌍·평가 청크를 동일 가중한 결과다. 입력당 팔별 12셀, 전체 120행이다. p값을 계산하지 않았다.

| 입력 | 직접 INT4 | 동일 위치 잔차 | 동일 위치 affine | 국소 대응 잔차 | 국소 대응+affine | 주 대비 개선 |
|---|---:|---:|---:|---:|---:|---:|
| p0 | 0.06512566 | 0.04192961 | 0.03854209 | 0.04052306 | 0.03766651 | **2.27175%** |
| p4 | 0.06048968 | 0.04792979 | 0.04147372 | 0.04597146 | 0.04018177 | **3.11511%** |

주 대비는 `1−대응+affine / 동일위치 affine`다. 단순 동일 위치 잔차에서 affine만 추가한 개선은 각각 8.08%/13.47%였다. 따라서 지도 없이 기준 예측기를 보강한 이득보다, 그 위에 국소 대응을 추가한 이득이 작았다. 이 affine는 TempoKV의 시간 이력·K→V 예측 전체를 재현하지 않으므로 기존 최선 방법보다 좋다는 결론도 내리지 않는다.

지도는 실제로 nonzero를 골랐다. nonzero 비율의 프레임 쌍 평균은 p0 21.55%, p4 47.84%다. 전역 이동과 달리 부분 대응이 있었으나, 그 사실이 큰 압축 이득으로 이어지지는 않았다. 층0에서 개선이 크고 층14에서는 작았으며, p4 층29 K에서는 소폭 악화했다. 공유 지도가 모든 층·K/V에서 같은 이득을 주지는 않는다. 층별 K/V와 원래 위치 RoPE 후 K 오차는 [전체 CSV](rows.csv)에 남겼다.

이번 표는 청크 6/7만의 결과이므로 이전 진단의 청크 0/1/6/7 평균과 숫자가 다르다. 실제 attention 읽기·출력 오차와 MUSIQ·움직임·주체 일관성은 측정하지 않았다.

## 저장 바이트와 계산 비용

아래 payload는 **3층의 K/V 참조+대상 프레임 코드·scale·padding과 해당 계수·지도**다. 지도는 모든 층·K/V가 실제 공유하는 int8 `[B,N,2]` 객체 한 번만 센다. 프레임 쌍마다 3,120바이트다. affine 계수는 3층 합계 36,864바이트이며 FP16 저장값을 예측에 사용했다. 계수는 프롬프트 내 재사용하지만 한 쌍의 상주 payload에 포함한다.

| 팔 | 실제 byte-container payload | 가상 INT4 packed 추정 |
|---|---:|---:|
| 직접 / 동일 위치 잔차 | 32,514,048 B | 18,063,360 B |
| 동일 위치 affine | 32,550,912 B | 18,100,224 B |
| 국소 대응 잔차 | 32,517,168 B | 18,066,480 B |
| 국소 대응+affine | 32,554,032 B | 18,103,344 B |

주 대비의 실제 payload 증가는 **0.009585%**로 고정한 1% 이내다. 참조 복원 작업공간은 3층 합계 28,753,920바이트이며 CSV에 별도로 기록했다. 원본 진단 입력·학습용 텐서는 배포 시 공짜 버퍼가 아니다. 고정 참조 ID/geometry 등의 범용 직렬화 헤더·전체 cache eviction·패킹 커널은 구현하지 않았다. 이 표를 전체 모델 상주량이나 가상 packed의 실제 절감량으로 부르지 않는다.

워밍업 1회 후 3회 반복 중앙값을 프레임 쌍마다 구했다. 아래는 그 8쌍 중앙값의 요약이며, 단계 중앙값의 합이 직접 측정한 end-to-end 지연은 아니다.

| 단계 | 동일 위치 affine | 국소 대응+affine |
|---|---:|---:|
| 3층 참조 encode+restore | 1.096 ms | 1.096 ms |
| 공유 지도 검색(쌍당 한 번) | 0 | 4.127 ms |
| 3층 K/V target encode | 1.428 ms | 2.410 ms |
| 3층 K/V target decode | 0.616 ms | 1.582 ms |

지도 바이트보다 검색·gather의 연산 비용이 두드러졌다. 다만 Python/PyTorch 구현의 finite/범위 검사와 동기화도 포함하므로 최적화된 kernel의 근본 하한으로 해석하지 않는다. 모델 전체 추론 속도는 재지 않았다. affine 계수 적합은 p0 0.180초/p4 0.079초였으며, 초기 CUDA 커널 비용 차이도 포함한다. 진단 루프는 파일 검증·적합·반복 계측·평가 포함 1.523초였고 프로세스 import/초기 시작은 제외한다. 프로세스 peak allocated 0.387 GiB, reserved 0.508 GiB는 진단 텐서의 메모리이며 배포 cache peak가 아니다.

## 검증·한계·판단

CPU 합성 검사 6개가 통과했다. 실 데이터에서는 forced identity 지도를 통한 전체 잔차 encode/decode가 동일 위치 코드와 같은지 96건 확인했다. 입력 캡처 24개 SHA256을 확인하고 지도 8개·FP16 계수 2개를 로컬에 보존했다. 새 모델 실행은 없으며 원본 캡처의 BF16/RoPE identity 이력을 재사용한다.

읽기 전용 감사가 120행·비용 40행·지도 8개·계수 2개·캡처 24개 해시, 실제 지도 source의 경계 유효성, 학습 토큰 수 6,240/계수 적합 분할, 요약과 GO 조건을 재확인했다. 같은 작성 주체의 재검토이며 외부 독립 검증은 아니다. 모델/codec 수치 실행을 별도로 재현한 감사도 아니다.

```bash
cd ~/Quantization
~/sfq_data/py tools/audit_dense_motion_probe.py --tensors
bash tools/watch_progress.sh 0
```

이 결과는 **현재 raw-K MSE 선택 규칙·반경·공유 지도·고정 affine 조합**의 투자 기준 실패다. 지도는 최종 잔차 양자화/attention 오차를 최소화한 최적해가 아니고, 대응 팔 전용 계수도 다시 학습하지 않았다. 모든 국소 대응이나 다른 압축 표현의 불가능성을 증명하지 않는다. 그러나 이번 추가 이득으로 큰 영상 실험·독립적인 새 방법 기여를 정당화하기도 어렵다. 단순 동일 위치 예측 개선은 기존 예측 압축과 가까워 신규성 근거로 삼지 않는다.
