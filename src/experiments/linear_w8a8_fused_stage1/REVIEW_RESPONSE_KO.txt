수용한 핵심 지적
- Q 1개 유효 이득, FFN 확장 유효 성능 미달, FFN 축소 대조군 정확성 조건 실패로 미판정.
- 실제 경로는 INT8 Triton GEMM+행 scale과 별도 최종 후처리다. FP32 M×N 버퍼가 남는다.
- 자동 튜닝과 융합을 동시에 바꿔 융합의 단독 효과를 측정하지 못했다.
- BF16/INT8의 실제 autotune 후보 집합은 PyTorch 구현상 다르다.
- 반복 구간은 입력 일반화 구간이 아니며 최초 컴파일 비용을 별도 보고한다.
- JSON의 전역 compiler_config와 options_by_arm을 구분한다.

수정하거나 유보한 해석
- '이득의 원천은 융합이 아니라 GEMM 교체'라는 단정도 대조 팔이 없어 확정하지 않는다.
  실제 kernel 변경은 확인했지만 결합 개입의 전체 이득으로만 보고한다.
- 'W8A8 정확성 동등'은 BF16과 정확 일치로 읽힐 수 있으므로 등록 오차 조건 통과로 표현한다.
- default/fused 최종 BF16 일치로 내부 INT32 누산 전체의 일치를 증명할 수는 없다.
- FFN 축소의 BF16 차이를 누산 순서/1ulp로 설명하는 것은 미검증 추측이다.
  등록 .002 한도가 부적절했다고 결과를 보고 확정하지 않으며 결과·한도를 유지한다.
- eager 기준선만의 추가 GPU 타이밍과 새 대조 팔을 CPU만으로 얻을 수는 없다.
  향후 CPU FP32 참조 설명 검사와 새 GPU 측정을 분리해야 한다. 이번에는 추가하지 않는다.
- 리뷰의 '전체196.6초'는 준비부터 GPU 단계 종료까지다. 이후 감사·리뷰 시간을 포함하지 않는다.
- 리뷰 문두의 14:10~14:20 UTC는 보고 파일 수신 전 미래 시각을 포함한다. 정확한 작업 종료
  계측으로 사용하지 않는다. 실제 실행 영수증과 completion.json의 수신·마감 기록을 사용한다.

GPU 재실행이나 실험 기준 변경은 없다. Fable이 텐서 재계산을 했다고 주장하지 않는다.
