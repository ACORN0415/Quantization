A-1 독립 검토 반영
Fable은 A-1 측정·정확성·실패 판정을 타당하다고 확인했다. 실제 trace와 shape1 출력코드를 직접 읽었다.
기본 compile이 항상 Triton INT8 GEMM이라는 이전 의견을 철회한 점을 반영했다.
같은 외부 _int_mm를 두 번 실행한 정수 일치를 Triton GEMM 검증이라고 부르지 않는다.
1259/0/571개의 독립quant 정수 차이와 전체 내부값 관측의 한계를 그대로 보고한다.

받아들이지 않은 해석:
- 독립 구간 합이 전체와 비슷한 사실만으로 중첩 부재나 대역폭의 물리적 바닥을 확정하지 않는다.
- 기억 기반4090 피크사양은 근거에서 제외한다.
- B의 과거V 부족, K개입과 V개입의 지표 차이는 수용한다. 바이트가 다른 팔을 동일바이트라고 표기하지 않는다.
- A-2의 .t() view 변형은 채택하지 않는다. torchao v0.9.0 kernel/intmm.py:60~62는 비연속mat2가
  잘못된 값을 줄 수 있어 contiguous로 바꾸는 것을 명시한다. 검토자의 일반적 레이아웃 지식은 이 구현의 근거가 아니다.
  https://github.com/pytorch/ao/blob/v0.9.0/torchao/kernel/intmm.py#L60

조정자 결정: A-1의 직접 관측(외부GEMM 유지+INT32 버퍼+추가latency)과 공개 구현이 가리키는
GEMM+scale 융합 경로 하나를 A-2로 별도 등록한다. 이는 Fable의 레이아웃안과 다르며 사용자에게 차이를 설명했다.
별도30분/3캡처/새모델0/커널작성0, BF16에도 동일자동튜닝 기회를 준다. 기존후보를 무한 연장하지 않고
이 공개 경로의 실행 가능성과 전체호출 비용만 확인한다. 새로운 양자화 방법·논문 기여로 부르지 않는다.
