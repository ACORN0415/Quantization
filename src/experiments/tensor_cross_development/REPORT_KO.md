# 방법 1 개발 진단 결과

2026-10-30. 기존 개발 프롬프트 2개, 시드 1개, 층 3개. 보류 생성 실험이 아니다.

## 결론

공통 채널 인덱스 Fourier 근사의 1차 screening은 진행 조건을 통과하지 못했다. 사후 평균 보정도 해결하지 못했다. 다만 같은 저장 예산의 **SVD 인자 표현은 2비트 RTN보다 출력 오차를 p0에서 22.74%, p4에서 19.56% 줄였다.** 따라서 방법 1 전체를 폐기하지 않고, 2비트 예산의 열 선택/표현 손실을 다음 좁은 질문으로 남긴다.

이는 T-ARP의 성능 검증이 아니다. 이번 선택은 leverage score 상위 열을 사용하는 간단한 결정론적 대용이며, 논문의 adaptive randomized pivoting/가정은 구현·검증하지 않았다. SVD 우위는 기존 수학 방법의 개발 관찰이며 신규성 증거도 아니다.

## 출력 오차

새 chunk6 V의 압축 오차가 미래 chunk7 query 32개의 post-Wo 출력에 더한 squared error D. K와 나머지 캐시는 BF16 기준이다. 두 cache 창에서 평균하고 3개 층을 평균했다. 전체 출력/FR 품질 지표가 아니다.

| RTN 기준 예산 | 프롬프트 | RTN D | 공통 열 / RTN | 평균 보정 / RTN | SVD / RTN |
|---|---|---:|---:|---:|---:|
| 2비트 | p0 | 0.04890183 | 1.748 | 1.704 | 0.773 |
| 2비트 | p4 | 0.03349426 | 1.689 | 1.684 | 0.804 |
| 3비트 | p0 | 0.00511257 | 12.709 | 12.451 | 5.091 |
| 3비트 | p4 | 0.00321878 | 14.400 | 14.280 | 5.835 |
| 4비트 | p0 | 0.00093662 | 52.629 | 51.864 | 19.860 |
| 4비트 | p4 | 0.00055839 | 65.400 | 64.769 | 25.101 |

비율은 낮을수록 좋다. 모든 54개 원시 행과 후속 36개 행을 보존했다. 미래 query로 인덱스/계수를 학습하지 않았다.

## 무엇이 막혔는가

- 예산별 rank는 22/29/36이다. 3비트 예산에서 공통 근사의 평균 V 상대 L2는 0.444, 같은 rank의 Fourier SVD 최적 잘림 잔차는 0.331, RTN은 0.182였다. 열 선택 손실과 rank 자체의 정보 손실이 모두 존재한다.
- 이 SVD 잔차는 해당 tensor Frobenius norm에 대한 rank 제약 근거이지 attention 출력 오차의 하한이 아니다. 실제 SVD 출력 검사에서도 2비트만 개선됐고, 3/4비트는 RTN보다 나빴다.
- 프레임별 평균 오차를 보존해도 D 개선이 작았다. 현재 실패를 평균 편향 하나로 설명할 수 없다.
- 공통 인덱스와 프레임 독립 근사의 차이는 일정하지 않다. Fourier 변환과 계수 표현도 달라지므로 공통 인덱스만의 인과 효과로 해석하지 않는다.

## 바이트·시간·검증

1개 층의 V payload만 비교한다. K 저장 및 전체 모델 캐시는 포함하지 않는다. FP16 인자와 int32 인덱스를 실제 tensor storage로 계수했다. 직렬화 파일 헤더/allocator overhead는 별도이며 배포 메모리라고 부르지 않는다.

| 기준 예산 | RTN bytes | 공통 열 bytes | 평균 보정 bytes | SVD bytes |
|---|---:|---:|---:|---:|
| 2비트 | 2697216 | 2674848 | 2684064 | 2673792 |
| 3비트 | 3595776 | 3525936 | 3535152 | 3524544 |
| 4비트 | 4494336 | 4377024 | 4386240 | 4375296 |

첫 진단 계산 구간 6.66초(모듈 import 제외), peak allocated 0.522 GiB, reserved 0.564 GiB. 모델 실행 없이 저장된 텐서를 이용했다. 공통 방식 encode는 층당 약 112–124ms, decode 약 0.33ms였지만 warm-up/반복 없는 첫 측정이므로 속도 우위 주장에 쓰지 않는다. SVD 참고 방식의 정밀 속도는 측정하지 않았다.

입력 SHA, 소형 full-rank 복원, payload 예산, finite 결과, 36개 저장 상태의 CPU/GPU 복원 일치를 검사했다. 기존 change-mixed 실험의 RTN 출력도 다시 일치했다. 이는 같은 작성자의 재계산이며 독립 검증이 아니다.

## 다음 한 단계

방법 1의 다음 구현 후보는 2비트 예산에서 adaptive pivoting/안정화된 열 선택을 실제로 구현하여 SVD와의 간극을 줄이는 것이다. 같은 예산의 SVD 인자 표현은 반드시 기준선으로 유지한다. 개선되더라도 다른 개발 시드와 더 많은 읽기에서 먼저 확인해야 한다. RTN만 이기고 기존 SVD와 차이가 없다면 새로운 방법의 기여는 약하다. 방법 2–4 및 긴 영상 생성은 이번에 실행하지 않았다.
