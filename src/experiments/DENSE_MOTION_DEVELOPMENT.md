# 국소 대응 KV 잔차 압축의 별도 개발 진단

2026-10-29. 실제 새 측정 전에 정한 계획이다.

## 질문과 이전 중단의 관계

전역 정수 이동은 두 개발 입력에서 zero shift만 선택하여 NO-GO였다. 그 결과와 기준은 바꾸지 않는다. 사용자 요청으로 **토큰마다 다른 국소 대응을 허용하는 별도 개발 가설**을 연다. 이전 NO-GO를 통과로 바꾸기 위한 재분석이 아니다. 전체 물리적 움직임 추정·신규성·영상 품질은 이번 주장이 아니다.

질문: 동일 위치의 학습된 affine 예측기에 비해, encode 시점에 있는 현재 K로 찾은 국소 대응이 INT4 잔차 복원 오차를 추가로 줄이는가? 캐시 원래 위치를 유지하고 복원 참조만 gather한다. 미래 query/프레임은 사용하지 않는다.

## 고정 입력·팔

- 이미 본 p0/p4, seed101, 층 0/14/29의 이전 캡처만 사용한다. 파일 24개의 SHA256을 확인한다. 새 모델 실행·새 보류 데이터·영상 생성은 없다.
- 청크 0/1의 프레임 쌍 0→1,1→2로 affine 계수를 맞추고, 청크 6/7의 같은 쌍에서만 평가한다. 두 프롬프트 각각 따로 맞추며, 프롬프트 보류 검증으로 부르지 않는다. 평가 대상 K/V는 계수 적합에 쓰지 않는다. 이미 다른 진단에서 본 개발 자료의 분할이므로 확증 연구가 아니다.
- 참조는 매 독립 쌍의 원본을 직접 K4V4/g16 양자화 후 복원한 값이다. 원본 BF16 참조, 잔차 복원 chain, 무비용 pinned 참조는 사용하지 않는다. 기존 코어의 FP32 계산·FP16 scale·byte 코드를 그대로 사용한다.
- 5팔: 직접 양자화, 동일 위치 단순 잔차, 동일 위치 affine 잔차, 국소 대응 단순 잔차, 국소 대응+affine 잔차.
- affine는 feature(head/channel)별 `a*reference+b`다. 계수는 적합 입력에서만 얻고 FP16로 저장한다. 이는 학습 예측 기준선을 보강하는 작은 모형이며 TempoKV의 시간 이력·K→V 전체 방법 재현이 아니다. 대응 팔도 **같은 동일 위치 적합 계수**를 사용한다. 따라서 주 대비는 이 고정 예측기에서 reference gather를 추가하는 효과다. 모든 대응용 최적 예측기를 배제하지 않는다.
- 지도는 층0 현재 pre-RoPE K와 복원 참조 K의 원소별 예측 MSE로 고른다. 각 목적 토큰에 대해 반경 2의 5×5 후보 중 유효한 source만 허용한다. identity 포함·동률 우선, 경계의 invalid source/zero predictor/부분 토큰 제외는 금지한다. 지도는 모든 층·K/V가 공유한다. raw K 선택 목적과 affine 후 잔차 목적은 다르므로 불리한 결과가 모든 지도 최적화의 실패를 뜻하지 않는다.

## 평가와 진행 조건

각 평가 프레임 K/V 상대 L2 평균을 3층·2쌍·2청크에 동일 가중해 프롬프트별로 보고한다. 평가 2프롬프트×2청크×2쌍×3층×5팔=120행. pre-RoPE K를 주 요약에 쓰고 원래 위치 RoPE 후 K 오차도 분리 기록한다. 실제 attention 출력·영상 품질을 대신하지 않는다.

**두 프롬프트 모두** 대응+affine가 동일 위치 affine보다 요약 오차를 5% 이상 줄이고, 지도/계수 포함 실제 텐서 payload 증가가 1% 이내이며, 모든 게이트·finite·해시 검사를 통과할 때만 다음 타당성 검토로 간다. 5%/1%는 개발 투자 기준이다. p값·신규성·동일 rate 우월성·배포 효율을 주장하지 않는다. 실패하면 이 규칙/해상도/예측기의 개발 변형을 종료하며 반경·기준선·입력을 바꿔 GO를 구제하지 않는다.

지도는 목적 토큰당 int8 dy/dx 2바이트이며 K/V·층 사이 실제 공유 객체 한 번을 센다. 3층의 anchor+target code/scale/padding 합계, affine 계수, 지도와 복원 참조 작업공간을 분리한다. 계수는 한 프롬프트의 모든 쌍에서 공유하지만 개별 쌍의 동시 상주 payload에 포함한다. 고정 geometry/비트폭/참조 ID의 범용 직렬화 헤더는 아직 구현하지 않는다. 가상 packed 추정과 실제 byte-container를 구분한다. bit packing/eviction 통합은 없다.

시간은 CUDA 동기화 후 reference encode+restore, 공유 map search, target residual encode, target decode를 구분해 측정한다. 지도 검색은 쌍마다 한 번이며 모든 층에 중복 더하지 않는다. 워밍업 1회 후 각 단계 3회 반복 중앙값을 기록한다. 진단 지표/파일 IO는 단계 시간 밖이다. 모델 포함 추론 속도가 아니며, 적합 비용과 peak allocated/reserved도 따로 적는다.

## 게이트·결과 위치

CPU 합성 검사: identity 지도, 비정형 국소 이동, 원래 목적 순서, 경계 유효 source, affine 적합·저장 계수와 오차, 실제 map/계수 바이트. 실 데이터는 평가 전에 원본 파일 SHA를 확인한다. 지도가 identity인 경우 동일 위치 팔과 복원이 같아야 한다. 새 모델 경로는 쓰지 않으며 이전 캡처의 BF16/RoPE 항등 이력만 인용한다.
