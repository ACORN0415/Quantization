실제 Claude Fable 검토: FABLE_REVIEW_KO.txt. 실제 세션 claude_b963a589_00ed_4256_bf1a_d353b16d1f27.
시작 /home/acorn0415, Orca native chat. Task 연결은 terminal_handle_stale로 실패했고 Task/Dispatch ID는 없다.

수용: C의 실용성 전망이 낮다는 지적, 기존 RTN/W8A8 경로가 SVD를 쓰지 않는 점,
TT 종료 유지, B의 더 낮은 예산/층별 배분을 실제 요구 없이 늘리지 않는 판단.

다르게 선택한 부분: 사용자가 이후 'C로 일단 진행하자'고 명시했다. C를 취소하거나
A 영상 검사로 바꾸지 않고 CPU30분 제한으로 실제 입력의 분해정밀도 효과만 측정했다.
실행명세·코드·단위검사를 결과 전에 커밋했고 별도 src/experiments/svd_precision_stage1에 보존한다.
새 TT 방법이나 NVIDIA 반복정련 구현·GPU속도 확인으로 확대하지 않는다.

그대로 채택하지 않은 근거/제안:
- 검토자의 합성 SVD 수치는 코드·실행 로그·원자료를 주 작업자가 독립 확인하지 못했다.
  이를 실제 입력 결과나 C 실행의 성공/실패 근거로 사용하지 않는다.
- A의 상대L2와 B의NSE를 직접 같은 값으로 비교하지 않는다. 같은 척도로 변환하더라도
  서로 다른 설정의 값만으로 같은 품질 gate를 요구할 수는 없다.
- A-3의 약5% projection은 다른 분모를 사용한 근사다. 실제 전체 가속의 엄밀한 상한이 아니다.
- A 영상 검사에 제안한 DINO0.90/0.85 문턱은 검증된 수용 기준이 아니며 현재 등록하지 않는다.
  B-4는 S120 대비 충분성 검사였고 BF16 동등성을 수용한 기록이 아니다.
- 저장 A 영상의 평가는 별도 질문으로 검토할 수 있지만, 사용자가 선택한 이번 작업은 C뿐이다.
  기존 A-4 실패 판정을 바꾸거나 새 timing을 시작하지 않았다.

검토자의 의견과 C 결과가 같은 방향이어도 두 모델의 동의를 실험 증거로 세지 않는다.
새 판단은 C의 실제 입력·패킹·출력 오차와 독립 CPU 감사에 근거한다.
