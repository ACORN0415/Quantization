작업: Quantization 프로젝트의 Claude 검토자·지도교수 역할 설정을 검토한다.
작업 디렉터리: /home/acorn0415/Quantization

사용자 요청:
“너는 하위 agent로 클로드를 사용할거야.
너가 작업을 하거나 무언가 했을 때는 클로드가 reviewer이자 교수님의 역할로서 확인하게 하고,
의견을 내거나 새로운 안을 냈을 때 같이 새로운 안을 낼 수 있게 해줘.”

당신은 실제 Claude 작업자이며 이 설정의 독립 검토자다.
다시 Claude나 다른 검토자를 생성하지 않는다.
이번에는 연구 후보를 진행하지 말고 설정만 검토한다.

읽을 대상:
- /home/acorn0415/Quantization/AGENTS.md
- /home/acorn0415/Quantization/CLAUDE.md
- /home/acorn0415/Quantization/docs/CLAUDE_REVIEW_PROTOCOL_KO.md
- 필요하면 git diff / git status로 현재 변경 범위를 확인한다.

검토할 질문:
1. 사용자 요구인 실제 Claude 사용, 결과 검토, 공동 제안이 구체적으로 반영되었는가?
2. 검토가 단순 동조나 형식적 승인에 그치지 않도록 근거 확인과 이견 처리가 충분한가?
3. 재귀적 작업자 생성, 권한 없는 실험·변경, 과도한 사용자 승인 요청을 유발하는가?
4. 실용적으로 고칠 규칙이 있다면 꼭 필요한 수정과 선택적 제안을 구분해 제시하라.

권한: 읽기 전용. 파일 수정·커밋·GPU 실행·모델 다운로드·환경 설치·외부 메시지 금지.
허용: 대상 문서 읽기, 읽기 전용 Git 확인, 조정자에게 Orca 보고.
설정 검토가 목적이므로 인터넷 조사나 새로운 연구안 도출은 필요하지 않다.

반환 형식: 한국어로 판단, 중요한 지적과 근거 위치, 필요한 수정, 직접 확인 범위.
수정이 필요 없다면 명확히 말하고 형식적 문제를 만들어내지 않는다.
실제 Claude 연결 확인을 위해 역할 이해도 짧게 설명한다.
검토 결과를 자신의 Orca Task/Dispatch에서 worker_done으로 반환한다.
파일 읽기 실패 등 검토 불가 사유는 성공으로 보고하지 않는다.
