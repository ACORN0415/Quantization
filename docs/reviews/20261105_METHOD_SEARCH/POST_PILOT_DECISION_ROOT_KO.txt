전체 생성 pilot 이후 자원 판단 — root, 2026-11-05

현재 결정
FULL pilot의 stop_quality를 유지한다. 이번 입력에 seed·새 팔·문턱을 덧붙이지 않는다.
다음 소규모 계산은 기존 개발 자료의 fixed_rotation_control에 한정해 검토한다. 목적은 이미 관측한 국소 보상 이득이 더 단순한 보정 기반 회전으로 대체되는지 확인하는 것이다. 통과하더라도 전체 생성 실패를 취소하지 않으며 새 방법의 신규성을 입증하지 않는다.
기존 Fable의 paired 응답 보정 제안은 D001에서 OBQ를 먼저 검사하기 위해 미뤘던 항목이다. 이미 실제 검사가 이뤄졌는지 확인한 뒤에만 후속 의사결정 대상으로 남긴다. 현재는 구현·실험을 승인한 상태가 아니다.

관측과 가설의 경계
1. 두 새 입력에서 FULL의 후반 NSE와 DINO 참조 유사도는 두 RTN보다 개선됐다. 두 번째 입력의 NSE 개선폭은 등록10%에 미달했고, R_bf16 대비 MUSIQ -2.179점으로 중단했다.
2. rain_market의 BF16 MUSIQ64.22는 압축 팔72.18~74.42보다 낮았다. 이 자료는 BF16 궤적 충실도와 무참조 화질 점수의 순위가 같지 않음을 보인다. MUSIQ가 잘못됐다거나 압축이 영상 생성 과제에서 더 좋다는 결론은 아니다.
3. rain_market의 후반 인접 프레임 DINO 유사도는 BF16 약0.9794, 압축 팔 약0.9963~0.9969였다. 이는 특징 변화가 작다는 단서일 뿐 동작 정지·장면 고착의 직접 검증이나 인과 설명이 아니다. 프레임을 독립 표본으로 세지 않는다.
4. 현재 작은 진단의 K 목적은 raw-logit 제곱 오차다. attention 출력과 실제 생성 전체의 최적화 목적이 동일하지 않다는 것은 수학적으로 명확하지만, 이번 실패의 원인을 특정한 것은 아니다. V, 보정 입력 범위, 생성 피드백, 평가 항목이 함께 달라질 수 있다.

새 제안 전 좁은 문헌 확인 (원문을 열어 확인한 범위만)
- Quantized Keys Steal Attention, arXiv2605.26266v1, §4/6: 캐시의 logit 잡음이 softmax 질량을 이동시키는 현상과 score 보정이 이미 연구됐다. 원문은 비균일/편향 오차 및 집중 attention에서의 제한을 적는다. 우리 S4/S5에도 관련 검사가 있으며 README와 후속 정정이 옛 강한 인과 주장을 축소했다. 이를 새 현상으로 제안하거나 새 pilot의 원인으로 단정하지 않는다.
  https://arxiv.org/html/2605.26266v1
- FlagRot, arXiv2611.03992v1, §3.1/C.1: 보정 query 통계로 I/H32/H128 변환을 선택한다. fixed17은 이 가족의 원리 대조이며 공식 시스템 재현이 아니다. 실제 연구 차이는 회전 선택이나 query 가중 오차 그 자체에 둘 수 없다.
  https://arxiv.org/html/2611.03992v1
- BoA, ICML2025 공식 초록: attention 모듈의 상호작용을 반영하는 Hessian으로 가중치 양자화를 최적화한다. 이번 확인은 공식 초록이며 본문 수식/코드는 추가로 읽지 않았다. 'attention을 고려한 Hessian'이라는 넓은 발상만을 새 기여로 주장할 수 없다.
  https://proceedings.mlr.press/v267/kim25j.html
- QuantMLA2609.36760v1의 초록/도입부와 RoLaQ2610.20686v1의 초록/도입부: 공유 latent의 K/V 경로가 결합된 오차를 attention-output supervision으로 다룬다. 자기회귀 영상과 동일 문제를 풀었다는 뜻은 아니지만 'K/V를 함께 고려'·'텐서 MSE 대신 출력 오차'만으로는 차별점이 부족하다. 성능 수치는 우리 환경으로 전이하지 않는다.
  https://arxiv.org/html/2609.36760v1
  https://arxiv.org/html/2610.20686v1
검색에서 직접 일치하는 제목을 못 찾은 것은 신규성 근거가 아니다. 이번 확인은 광범위한 새 후보 수집이 아니라 기존 제안의 과장 방지다.

후속 검토가 답해야 할 선택 하나
기존 강한 단순 양자화/잔차 복원보다 작은 상태로 실제 attention 응답 차이를 보존할 가치가 있는가?
같은 총 바이트에서 비트 증가와 PSAC를 먼저 비교해야 한다. 단순 '부호 있는 보정'이나 공통 feature 차분은 control-variate/선형 attention 계열과 가까우므로, 기존 signed base-aware 방법보다 작은 실제 비용에서 더 나은 보류 입력 선택을 만드는지까지 확인해야 한다.
그 필요성이 관측되지 않았다면 학습 어댑터·커널 구현으로 넘어가지 않는다. 기존 pilot의 결과는 이 제안의 긍정적 실증으로 세지 않는다.
