사용자 지시와 진행 기준 — 2026-11-05

목적: 신규 방법의 추가 효과를 설명할 수 있는 검증물을 확보할 때까지 관측 → 후보 → 사전등록 → 실험 → 반론 검토를 반복한다.
성공을 보장하거나 부정 결과를 숨기지 않는다. 단순 점수 상승이나 두 에이전트의 동의는 신규성 증거가 아니다.

사용자 최신 배정: 업무마다 Claude Fable 1명 + Codex 1명. 이번 두 업무에 각각 한 쌍, 총 네 명.
업무 1: 회전+head 정밀도 결과의 비교 조건 감사 및 동일 조건 CPU 진단.
업무 2: 회전 후 남은 실제 오류를 대상으로 선행연구와 구별되는 방법 후보 하나의 독립 설계.
주 작업자: 두 쌍의 근거 대조, 선택 및 사전 기준 확정, 실제 실행과 누적 지식 관리.

기존 GPU R-8d를 방해하지 않는다. 먼저 CPU/읽기 작업을 수행한다.
기존 데이터와 실행 파일은 덮어쓰지 않는다. 새 결과는 독립 디렉터리에 둔다.
첫 검토 각 15분, CPU 진단은 설계 검토 후 별도 고정 상한. 데이터 다운로드나 저장량 확장은 실제 필요만 허용한다.
장기 연구 전체에 성공할 때까지라는 사용자 요청이 있으나, 개별 실험에는 자원 상한과 실패/판단불가 조건이 항상 필요하다.

완료 기준: 강한 단순 기준선 및 근접 방법 대비 의미 있는 이득이 새 보류 입력에서 재현되고,
실제 저장량/시간/메모리의 필요한 비용과 검증된 차별점이 설명되는 방법론 증거 묶음.
기존 seed/프롬프트를 반복해서 골라 성공시킨 결과만으로 완료하지 않는다.
