잔여·주의 (비차단)
- reset()이 failure 문자열을 지운다. 실패 generation의 기록은 caller/verifier가 예외 시점에 보존해야 한다.
- current_start 정수 타입 검사(161)는 pipeline이 Python int를 넘긴다는 전제다(CI:318/412의 누적은 int). 다른 타입이면 fail-closed다.
- read는 매 호출마다 부분 span 전체를 복원(decode)한다. 이는 비용이다.
- 상주량 W+21 frame은 논리값이다. 실제 바이트, workspace, GPU peak는 미측정이다.
- attention_fn과 rope_fn은 주입되므로, 실제 연결은 실행 단계의 binding으로 확인해야 한다.
