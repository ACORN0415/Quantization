고정 Gaussian rank32 paired-response 진단 — 실행 및 Codex 감사 결과
작성: 2026-11-05, root. 실제 Claude Opus 5.5의 결과 해석 검토는 별도 진행 중.

판정: stop_fixed_Gaussian_rank32
등록한 4개 개발 평가점 × 3개 난수 seed에서 개선 기준을 충족하지 못했다.
같은 추가 저장 상한 안의 등록 기준선 12개 중 최소 SSE에 비해 후보 SSE가
80.56~168.13% 컸다. 원래 R_fp32 기준선보다도 12개 경우 모두 SSE가 컸다.
따라서 이번 고정 Gaussian rank32 인스턴스는 종료한다. rank/seed/기준을
결과 뒤에 바꾸어 같은 진단을 연장하지 않는다.

1. 무엇을 시험했는가
동일 과거 K/V, 현재 BF16 청크, query, CPU attention 및 post-Wo 평가에서
paired 분자·분모 보정과 강한 단순 기준선·기존 방법의 결합을 비교했다.
총 17개 팔 × 4개 개발 평가점 = 68행이다. 데이터는 causal seed307의
layer18/24, chunk7, read0/3이다. p0_s101은 보정에만 사용했다.
평가는 K-only 참조(원래 K와 공통 V4)를 중심으로 하며 전체 BF16 참조 오차도
별도로 저장했다. 이는 독립 보류 입력이나 전체 영상 품질 검사가 아니다.

추가 상태 상한은 층별 6개 과거 청크 기준 1,806,361B이다.
PAIR는 1,403,904B, FULL은 786,432B, FULLP1/FULLP1Q는 1,800,600B다.
동일 상한 비교이며 실제 사용량이 같다는 뜻이 아니다. 전체 프로세스 RSS,
임시 계산 공간, 공통 상태는 이 추가 상태 상한과 구분한다.
FM3/FM8은 등록대로 상한 밖 비교로 유지했다.

2. 저장 결과
각 평가점의 가장 좋은 등록 기준선과 PAIR/그 기준선의 K-only SSE 비율:

L18/read3   FULLP1      275.587570       2.001855  2.003267  2.000210

L24/read3   FULLP1      130.662155       1.805557  1.861595  2.681303

비율 1 미만이면 개선이다. 등록 기준은 모든 평가점·seed에서 0.9 이하,
fallback 비율 0.1% 이하, 저장 상한 충족이었다. 통과는 0/12다.
이 표의 최소 기준선 선택은 등록된 진단 비교이며, 배포 시 알 수 있는
선택 규칙이나 사전 선택기의 성능으로 해석하지 않는다.

fallback은 L24/read0/seed43에서 1/1536, 나머지 11개에서 0/1536이었다.
모두 등록된 fallback 기준을 충족했다. 후보 종료 사유는 오차 감소 부재다.
분모 이상으로 fallback이 많아서 효과가 가려졌다는 설명은 이 결과와 맞지 않는다.
분모 통계의 중앙값이 작다는 사실만으로 보정 전체가 모든 query에서 작거나
영향이 없다고 결론 내리지 않는다. 다른 학습 특징이나 모든 paired 방법의
실패를 증명한 것도 아니다.

3. 실행 유효성과 최초 실패
최초 V4 실제 실행은 4.033초 뒤 첫 패킷 해시 검사에서 무효 종료됐다.
생산자의 code_sha256은 packed uint8 바이트인데 소비자와 합성 fixture가
unpacked int8 바이트로 잘못 해석했다. 이 실행에서는 query/attention/SSE 및
후보 점수를 계산하지 않았다. 합성 경로 완주가 외부 생산자 계약 검증을
대신하지 못했다는 구현 검증의 누락도 함께 보존한다.

원래 1회 계획에 대한 추가 실행 1회 예외를 명시적으로 기록했다.
Codex와 실제 Opus의 원인·소스·계약·감독기 검토 후 V5를 별도 폴더에 고정했다.
원래 입력, 팔, 기준, 45분 절대 마감은 유지했다. 원 V4 자료 8개는 그대로다.
두 번째 실제 실행 V5는 36개 단계가 모두 exit0이고, 외부 감독기도
completed / supervisor_exit_code 0을 기록했다. 세 번째 실제 실행은 하지 않았다.

5. 남길 판단
작은 추가 상태로 오차 응답을 근사한다는 아이디어만으로 강한 기준선을 넘지 못했다.
이번 고정 특징은 기본 양자화 오차도 줄이지 못했다. 더 큰 rank나 유리한 seed를
사후 선택하는 것으로 구제하지 않는다. 후속 연구는 별도로 관측된 미해결 문제와
단순 기준선에서 시작해야 하며, 기존 전체 영상 pilot의 stop_quality도 유지한다.
이 결과는 새 방법론의 성공이나 연구 전체의 종료를 뜻하지 않는다.
